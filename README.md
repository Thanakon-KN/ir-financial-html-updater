# IR Financial HTML Updater

A Codex skill for updating investor relations financial HTML snippets and chart data from Excel workbooks, in English and Thai.

## Contents

- `SKILL.md` — workflow, data extraction guidance, and HTML update rules.
- `agents/openai.yaml` — skill display metadata.
- `references/page-patterns.md` — MASTER and SKR workbook patterns and examples.

## Installation

Copy this directory into your Codex skills directory:

```text
~/.codex/skills/ir-financial-html-updater/
```

Restart or refresh Codex so it can discover the skill. Invoke it with `$ir-financial-html-updater`.
