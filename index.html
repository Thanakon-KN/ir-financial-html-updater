Codex skill

IR Financial HTML Updater

Update investor relations financial highlights, charts, and homepage KPIs from Excel workbooks. Supports English and Thai pages.

View on GitHub Read the skill

What it does

  • Reads the relevant workbook sheets before updating numbers.
  • Preserves the existing HTML structure, language, classes, and components.
  • Separates annual and quarterly chart data, and flags source inconsistencies.
  • Handles Buddhist Era dates and Thai labels for Thai pages.

Install

  1. Copy this repository into ~/.codex/skills/ir-financial-html-updater/.
  2. Refresh Codex so it discovers the skill.
  3. Invoke it with $ir-financial-html-updater and provide the workbook and page snippet.

Repository files

  • SKILL.md — workflow and update rules
  • Agent metadata — name and invocation prompt
  • Page patterns — MASTER and SKR examples
